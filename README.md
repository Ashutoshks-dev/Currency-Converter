# 💱 Currency Converter

A browser-based currency converter built with HTML, CSS, and JavaScript. It fetches exchange rates from a public API and calculates conversions between different currencies.

## ✨ Features

* Convert between supported currencies.
* Fetch exchange rates using a public currency API.
* Display country flags based on the selected currencies.
* Calculate and display the converted amount.
* Handle API errors with a user-friendly message.
* Simple, interactive interface.

## 🛠️ Technologies Used

* HTML5
* CSS3
* JavaScript
* [Fawaz Ahmed Currency API](https://github.com/fawazahmed0/exchange-api)
* [FlagsAPI](https://flagsapi.com/)

## 🚀 How to Run

1. Clone or download this repository.
2. Open the project folder.
3. Open `html.html` in your browser.

No API key is required.
